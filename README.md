# weather-walk-map
# 날씨별 보행 불편 예측 지도 시스템

## 1. 프로젝트 소개
본 프로젝트는 날씨와 보행 환경을 분석하여 보행 불편 가능성이 낮은 이동 경로를 추천하는 독립형 모바일 지도 애플리케이션을 제안합니다.

## 2. 개발 배경
기존 지도 서비스는 주로 최단 거리와 이동 시간을 기준으로 경로를 추천합니다. 그러나 비나 눈이 내리는 날에는 경사로, 물이 고이는 구간, 미끄러운 보행로 등이 이동에 불편을 줄 수 있습니다. 이를 개선하기 위해 날씨와 보행 환경을 고려한 경로 추천 시스템을 제안합니다.

## 3. 주요 기능
- 기상청 API를 활용한 날씨 정보 수집
- OpenStreetMap을 활용한 보행로 정보 분석
- 강수량, 적설량, 경사도 기반 보행 불편 위험도 예측
- 위험 구간 지도 시각화
- 최단 거리 경로와 보행 불편이 적은 추천 경로 비교

## 4. 활용 기술
- Python: 데이터 수집 및 분석
- 기상청 API: 강수량, 적설량, 기온 정보
- OpenStreetMap: 지도 및 보행로 데이터
- NetworkX: 경로 탐색 알고리즘
- Folium: 지도 시각화

## 5. 향후 개발 계획
1. 기상 및 보행 환경 데이터 수집
2. 구간별 보행 불편 위험도 분석 알고리즘 설계
3. 경로 추천 기능 설계
4. 모바일 앱 화면 구성
5. 시범 지역 검증 및 개선

## 6. 프로젝트 진행 상태
현재 본 프로젝트는 제안 단계이며, 실제 애플리케이션은 아직 구현되지 않았습니다.
